# Smart Access Hub

Construye una plataforma web moderna, profesional y responsive para un sistema de control de acceso inteligente para condominios basado en reconocimiento biométrico multimodal y protección de datos.

Esta primera versión es un MVP de validación y demostración, por lo que NO es necesario implementar todavía el reconocimiento facial, huella dactilar ni la comunicación real con dispositivos IoT. Sin embargo, la arquitectura visual y funcional debe quedar preparada para integrar esos componentes posteriormente. En el archivo Markdown adjuntado tiene las especificaciones del proyecto es importante que se revisen ahi se cientan las bases de la idea
